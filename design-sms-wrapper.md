## Problem Statement
Micro-finance managers in Nepal need to send reliable, bulk SMS (loan reminders, payment tracking) but existing tools like NestSMS are generic marketing pipes. The user currently relies on an AkashSMS reseller account but needs a vertical-specific wrapper that prevents spam and guarantees compliant, accurate messaging without manual effort.

## Demand Evidence
The founder has a specific approachable business—a small micro-finance manager—actively using NestSMS/other SMS services who needs this hyper-specific workflow.

## Status Quo
Users are paying standard rates to incumbents (NestSMS, AkashSMS) for a generic API/dashboard that doesn't understand the context of their financial data, forcing them to manually manage templates and compliance.

## Target User & Narrowest Wedge
The target user is the micro-finance manager.
The narrowest wedge is a Minimal Viable Agent that allows them to generate fixed templates using AI, validates the templates against spam/compliance rules using Laya, and bulk-sends the SMS via AkashSMS using standard string interpolation.

## Constraints
- Must prioritize compliance and accuracy over creativity (hallucinating loan amounts is unacceptable).
- Must utilize the AkashSMS reseller account as the underlying pipe.
- AI must NOT process every single CSV row (too expensive, slow, and prone to hallucinations).

## Premises
1. The AI must prioritize compliance and accuracy over creativity.
2. The product is a vertical-specific agent for finance/SMBs, not a generic mass-marketing tool.
3. The real value is the workflow automation layer on top of AkashSMS, not the SMS delivery itself.

## Recommended Approach
**Fixed Template Architecture with System-1/System-2 AI:**
Build a Next.js (frontend) + NestJS (backend) service with BullMQ.
- **System 2 (Heavy LLM / Template Engine):** Used *once per campaign* by the manager to draft a polite, perfectly formatted 160-character template with variables (e.g., `Dear {name}, your amount of {amount} is due.`).
- **System 1 (Fast Classifier / Spam Filter):** `convaiinnovations/laya` evaluates the drafted template *once per campaign*. It returns a strict probability score on whether the template is spam or non-compliant. If safe, the template is approved.
- **Execution (No AI):** The backend uses standard string interpolation to map the CSV rows to the approved template, then drops the batch into a BullMQ queue to fire to AkashSMS at maximum speed.

## Success Criteria
The micro-finance manager successfully sends a batch of loan reminders through the new wrapper, with 100% template accuracy, zero hallucinations, and instantaneous variable substitution.

## Distribution Plan
A Next.js frontend deployed for the client where the manager can draft templates, upload a CSV, and monitor the bulk send progress via WebSockets.

## Dependencies
- AkashSMS Reseller API credentials.
- System 2 API Key (Any generative LLM).
- System 1 API Key/Endpoint (Laya AI for classification).
